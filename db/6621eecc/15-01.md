2. 開發成功之技術或產品：

- (1) 新產品之開發，提升良率， OEM 生產出貨 

   - A.Type C 及 USB 4.1 等高頻寬線材生產採半自動動量產出貨 

電子裝置的中央處理器 (CPU) 速度持續倍增，象徵著裝置間和模組間的資 料傳輸速度亦隨之倍增。同時，隨著面板技術的不斷改善，對視訊頻寬的需求 也越來越高，傳統的線材已無法滿足需求。在歐盟的要求下，統一手持裝置的 充電傳輸連接器及線組已成為標準。在蘋果 / 英特爾和 USB 協會的主導下， 

Type C 和 USB 4.1 等線材勢必成為電子產品的標準配備。然而，這些規格的 高電流、高頻寬、低損耗和低回授要求對連接產業製造商構成了一大挑戰。今 晧多年來積累了豐富的線材技術，並與主要客戶建立了高度互信的合作關係， 成功開發了符合 USB 4.1 規格的線材。 Type C 線材經過多次修改，簡化了設 計並降低了成本，已獲得了協會的認證。在疫情的影響下，自動化生產成為主 要目標，通過生產技術的改進，已初步實現了主生產段的自動化生產，提高了 品質和產能，正式進入了量產使用的時代。 

B. 車類控制線組及邊緣運算應用之傳輸線組 

電動汽車和自動駕駛技術是當前熱門話題之一，也代表了汽車產業未來的
發展方向。在實現這一目標的過程中，邊緣運算數據的傳輸和可靠性至關重要，
以應對複雜路況帶來的心理壓力。新的自動車開發生產大廠因此會更換供應
商，這也為供應鏈帶來了新的機遇。然而，由於可能遭遇的挑戰，如氣候變化
等因素，電氣連接技術存在一定的技術門檻。雲端和邊緣運算是未來商業發展
的核心，其對線材的穩定性要求十分嚴格。今晧積極參與客戶的設計過程，提
供線材解決方案，確保電氣訊號傳輸穩定可靠，並成功通過客戶驗證，實現量
產上市。

在不斷的驗證和實踐過程中，科技進步將成為趨勢，涉及多媒體、定位、安全
和健康護理等領域。今晧將積極參與客戶的早期設計階段，擴展在電子產品領
域的經驗，共同開發適用於戶外運動的電子商品。目前已有多款車型使用我們
提供的控制線材，且車型數量不斷增加。

- D. 線材高頻測試設備導入更新及生產設備投入量產 

隨著顯示技術的不斷突破和進步，傳輸線材的要求也日益提高，需要具備
高傳輸速度、低回授、低串音和低阻抗等技術規格。為了滿足客戶對線材產品
的不斷需求，我們決定進一步投資導入測試線材高頻測試設備。

這些高頻測試設備將能夠有效地測試各種類型的線材，包括 TypeC 、 HDMI 、 USB 、電光混和線等，確保它們的高頻特性達到設計要求。通過在早期階段進 行測試和驗證，我們可以及時發現和解決設計和製程上的問題，從而提高產品 的品質和穩定性。 

一旦生產設備經過測試和修改後成功通過測試，我們就會考慮添購新的生產
設備，以便進入量產階段。這將有助於確保我們的產品在市場上能夠達到高水
準的品質和性能要求。
